# 해체공사 용어집

← [[해체공사 MOC]]

| 용어 | 뜻 |
|---|---|
| 해체 | 건축물 전체 또는 일부를 파괴·절단해 제거하는 것 (법령 용어) |
| 멸실 / 멸실신고 | 건축물이 없어진 상태 / 건축물대장을 정리하는 신고 |
| 허가권자 | 해체 허가·신고를 처리하는 시장·군수·구청장 |
| 해체계획서 | 해체 공법·순서·안전·환경 대책을 담은 계획 문서 → [[해체계획서]] |
| 해체공사 감리자 | 해체계획서대로 공사하는지 확인하는 사람. 허가권자가 지정 |
| 주요구조부 | 내력벽, 기둥, 바닥, 보, 지붕틀, 주계단 |
| 내력벽 / 비내력벽 | 하중을 받는 벽 / 칸막이 역할만 하는 벽 |
| 잔존 구조물 | 해체 도중 아직 남아 있는 구조물 |
| 동바리 (잭 서포트) | 슬래브를 아래에서 받치는 가설 지주. 장비 탑재 시 하부 층에 보강 |
| 성토 | 흙을 쌓는 것. 해체 장비 진입로로 쓰기도 하나 하중 위험 큼 |
| 압쇄기 (크러셔) | 콘크리트를 물어 부수는 유압 집게 |
| 장붐 압쇄기 | 붐이 긴 압쇄 장비. 지상에서 고층부 해체 |
| 브레이커 | 유압 해머. 소음·진동이 큼 |
| 와이어쏘 / 월쏘 | 다이아몬드 와이어·톱날로 콘크리트 절단 |
| 정적 파쇄제 (팽창제) | 구멍에 넣으면 팽창해 콘크리트·암반을 깨는 재료 |
| Strip-out (내부 철거) | 구조체 해체 전에 내장재·설비를 먼저 철거하는 것 |
| 분리배출 | 폐기물을 성상(종류)별로 나눠 배출 |
| 순환골재 | 폐콘크리트를 파쇄·선별해 다시 쓰는 골재 → [[순환골재]] |
| 분별해체 (선별해체) | 해체 단계에서 자재를 종류별로 나눠 해체하는 것. 단순파쇄의 반대 |
| 단순파쇄 | 건물을 한 번에 부순 뒤 잔해에서 골라내는 방식 |
| 부착 모르타르 | 순환골재 표면에 붙어 있는 기존 시멘트 페이스트. 흡수율↑ 밀도↓ |
| 프리웨팅 | 흡수율 높은 골재를 미리 물에 적셔 배합수 변동을 줄이는 것 |
| 혼합폐기물 | 분리되지 않은 폐기물. 처리비가 비쌈 |
| 올바로시스템 | 폐기물 인계·인수를 전자로 기록하는 시스템 (환경부) |
| 기관석면조사 | 지정된 석면조사기관이 하는 석면조사 |
| 석면 지도 | 건물 내 석면 함유 자재의 위치·종류·면적을 표시한 도면 |
| 지정폐기물 | 석면 등 유해성이 있어 별도 관리하는 폐기물 |
| 비산먼지 | 일정한 배출구 없이 날리는 먼지 |
| 특정공사 | 소음·진동관리법상 사전신고 대상 공사 |
| 세륜 시설 | 공사 차량 바퀴를 씻는 시설 |
| Scan-to-BIM | 3D 스캔 점군으로 현황 BIM을 만드는 것 |
| 4D / 5D BIM | 3D + 시간(공정) / + 비용·물량 |
| Material Passport | 자재의 재질·상태·재사용 가능성을 기록한 정보 |
| DfD (Design for Deconstruction) | 나중에 해체·재사용하기 쉽도록 하는 설계 |
