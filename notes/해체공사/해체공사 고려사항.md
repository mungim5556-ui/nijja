# 해체공사 고려사항

← [[해체공사 MOC]]

해체공사에서 고려할 사항을 **8개 범주**로 정리했다. 각 범주 끝에 BIM으로 다룰 수 있는 부분을 표시했다(🧊).

---

## 1. 구조 안전 (가장 중요)

해체 중인 건물은 **설계 당시와 다른 구조 시스템**이다. 부재가 사라지면서 하중 경로가 바뀐다.

- [ ] **잔존 구조물의 안정성**: 해체 단계마다 남은 구조가 자립하는가? (특히 기둥·벽이 일부만 남을 때)
- [ ] **장비 하중**: 상층 탑재 장비 무게 + 충격 하중을 슬래브가 견디는가? → 하부 동바리 보강
- [ ] **해체물(잔재) 적재 하중**: 해체물을 슬래브 위나 건물 옆에 **과도하게 쌓지 않는다**
- [ ] **성토(흙 쌓기) 금지 또는 검토**: 장비 진입용으로 흙을 쌓으면 하중이 급증한다 ([[광주 학동 붕괴사고]]의 원인)
- [ ] **전도 방향 제어**: 기둥·벽은 **건물 안쪽**으로 넘어지게 한다. 도로 쪽으로 넘어지면 대형 사고
- [ ] **해체 순서 준수**: 하부를 먼저 헐거나 내력벽을 먼저 제거하지 않는다
- [ ] **노후 구조물 상태**: 철근 부식, 콘크리트 강도 저하, 무단 증축으로 예상보다 약할 수 있다
- [ ] **지하층 해체 시 지반·인접 건물**: 지하 외벽이 흙막이 역할을 하고 있음
- [ ] **기상 조건**: 강풍·폭우 시 작업 중지 (분진망·가설재 전도, 살수 후 잔재 무게 증가)

🧊 BIM: 해체 단계별 구조 모델 → 구조해석 연계, 동바리 배치 모델링

## 2. 작업자 안전

주요 재해 유형: **추락, 낙하·비래, 붕괴·도괴, 협착(장비), 감전**

- [ ] 작업계획서 작성 및 작업자 교육 (산업안전보건기준에 관한 규칙 제38조)
- [ ] 해체 장비 작업 반경 내 **출입 금지**, 신호수 배치
- [ ] 개구부·단부 추락 방지 (안전난간, 안전대)
- [ ] 낙하물 방지망, 방호선반
- [ ] 장비 전도 방지 (지반 지지력, 경사)
- [ ] 잔존 전선 감전 (인입선 차단 확인)
- [ ] 분진·석면 노출 → 호흡보호구
- [ ] 동시 작업 금지 (상하 동시 작업 X)

🧊 BIM: 위험 구역(장비 반경, 낙하 위험 범위) 시각화, 4D 시뮬레이션 기반 안전 교육

## 3. 주변(공공) 안전

- [ ] **인접 건축물**: 거리, 구조 상태, 사전 상태 조사(균열 사진 기록 → 분쟁 대비), 계측(균열·기울기·진동)
- [ ] **도로·보행자**: 보도 통제, 우회 통로, 차량 통제, 신호수
- [ ] **버스정류장·횡단보도·지하철 출입구**: 해체 영향 범위 내에 있으면 **임시 이전 협의**
- [ ] 가설울타리·방호 구조물 강도
- [ ] 해체 영향 범위 (건물 높이만큼 쓰러질 수 있다고 보고 검토)
- [ ] 지하 매설물(가스관, 상수도) 손상 방지

🧊 BIM + GIS: 주변 건물·도로·정류장을 포함한 사이트 모델, 붕괴 시 영향 범위 시뮬레이션

## 4. 유해물질 (석면 등)

- [ ] **석면조사** 결과 확인 → 석면 지도 (위치·면적·종류)
- [ ] 석면은 **본 해체 전** 등록 업체가 제거, 작업 신고, 농도 측정, 완료 후 잔재물 확인
- [ ] 2009년 이전 건물은 석면 사용 가능성이 높음 (슬레이트, 천장 텍스, 보온재, 바닥 타일, 내화피복 등)
- [ ] PCB 함유 변압기·콘덴서, 형광등(수은), 냉매(프레온) 회수
- [ ] 납 함유 도료, 오염 토양 (공장·주유소 부지)

🧊 BIM: 부재 속성에 석면 함유 여부·종류·면적을 넣어 **석면 지도를 3D로** 관리

## 5. 환경 (소음·진동·분진)

| 항목 | 대책 | 관련 법 |
|---|---|---|
| 소음 | 방음벽, 저소음 장비, 작업 시간 제한, 브레이커 사용 최소화 | 소음·진동관리법 |
| 진동 | 압쇄·절단 위주, 진동 계측 | 소음·진동관리법 |
| 분진 | **살수·안개 분무**, 방진막, 세륜, 덮개 | 대기환경보전법 |
| 수질 | 살수·절단 냉각수 처리, 우수 유입 방지 | 물환경보전법 |

- [ ] 공사장 생활소음 규제 기준(지역·시간대별) 준수 #확인필요
- [ ] 특정공사 사전신고, 비산먼지 발생사업 신고 대상 여부 → [[해체공사 관련 법령#환경 관련 법령]]

## 6. 폐기물·자원순환

- [ ] 건설폐기물 **발생량 예측** (종류별: 콘크리트, 아스콘, 벽돌, 목재, 금속, 혼합)
- [ ] **현장 분리배출** (성상별 분리 → 재활용률·처리비에 직결)
- [ ] 처리업체 선정, 처리계획 신고, 올바로시스템 전자인계
- [ ] 콘크리트 → 순환골재, 철근·철골 → 고철 매각
- [ ] 재사용 가능 자재 선별 (철골 부재, 벽돌, 목재, 창호, 설비)
- [ ] 현장 내 임시 적치 위치·높이 (과적 금지 → 구조 안전과 연결)

🧊 BIM: 부재별 재질·체적 → **폐기물량 자동 산출(5D)**, 재사용 자재 목록(Material Passport)

> [!info] 더 보기
> 분별해체를 안 하면 고품질 순환골재를 만들 수 없다 → [[순환골재]]

## 7. 공정·비용·계약

- [ ] 공기: 석면 제거 기간, 인허가 기간 포함
- [ ] 비용: 해체비 + 운반비 + 처리비 − 고철·자재 매각 수입
- [ ] **불법 하도급·재하도급 금지** (단가 삭감 → 안전 소홀로 이어짐)
- [ ] 감리 비용은 건축주 부담, 감리자는 허가권자 지정

🧊 BIM: 4D 공정 + 5D 물량·비용 연동

## 8. 민원·커뮤니케이션

- [ ] 착공 전 주민 안내 (공사 기간, 작업 시간, 연락처)
- [ ] 인접 건물 사전 조사 결과 공유
- [ ] 소음·분진 민원 대응 체계
- [ ] 학교·병원 인접 시 작업 시간 조정

🧊 BIM: 3D 시각화 자료로 주민·발주처 설명
