# 해체공사 개요

← [[해체공사 MOC]]

## 정의

- **해체**: 건축물을 건축·대수선·리모델링하거나 멸실시키기 위해 건축물 전체 또는 일부를 파괴하거나 절단해 제거하는 것. (「건축물관리법」 제2조 정의 취지)
- **멸실**: 건축물이 해체, 노후화, 재해 등으로 효용이 없어진 상태. 해체 후에는 건축물대장을 정리하는 **멸실신고**를 한다.
- 실무에서는 "철거"와 "해체"를 섞어 쓰지만, 법령 용어는 **해체**이다.

## 신축 공사와 무엇이 다른가

| 구분 | 신축 | 해체 |
|---|---|---|
| 구조 상태 | 설계대로 완성되어 가는 구조 | **설계와 다른 상태로 계속 약해지는** 구조 |
| 정보 | 설계도서가 최신·완전함 | 도면이 없거나, 현장과 다르거나, 증·개축 이력이 반영 안 됨 |
| 주요 위험 | 추락, 낙하 | **붕괴·전도**, 추락, 낙하, 분진, 석면 |
| 산출물 | 건물 | **폐기물·순환자원** (콘크리트, 철근, 금속, 목재 등) |
| 공사 기간 | 길다 | 짧다 → 계획 소홀, 하도급·저가 수주가 쉬운 구조 |
| 주변 영향 | 소음·교통 | 소음·진동·분진이 더 크고, **도로·인접건물로 무너질 위험** |

> [!tip] BIM 관점 포인트
> 신축 BIM은 "만들어질 상태"를 모델링하지만, 해체 BIM은 **"현재 상태(As-is)"를 확보하고 "없어져 가는 과정"을 모델링**해야 한다. → [[해체공사 BIM 적용 포인트]]

## 해체공사의 분류

### 범위에 따라
- **전체 해체**: 건축물 전부를 없애는 해체 (재건축·재개발 대부분)
- **부분 해체**: 일부 층·부재만 해체 (리모델링, 증축 전 철거, 내부 철거)

### 공법에 따라 → [[해체 공법과 장비]]
- 기계식: 압쇄, 브레이커, 절단(와이어쏘·월쏘), 코어드릴
- 발파식: 화약을 사용하는 붕괴·전도 해체
- 정적 파쇄: 팽창제(비폭성 파쇄제), 유압 잭(유압 스플리터)
- 기타: 워터젯, 블록 해체(잘라서 크레인으로 내리기)

### 해체 방향에 따라
- **상부→하부 (Top-down)**: 국내 대부분. 위층부터 장비를 올리거나 지상에서 장붐 장비로 해체
- **하부→상부 (Bottom-up)**: 일본의 잭다운 공법처럼 아래층을 해체하면서 건물을 내리는 특수 공법. 고층·도심에서 소음·분진이 적다

## 해체공사 참여자

| 주체 | 역할 |
|---|---|
| 건축주(관리자) | 해체 허가 신청/신고, 감리 비용 부담, 최종 책임 |
| 해체계획서 작성자 | 건축사 또는 기술사 (허가 대상 등) → [[해체계획서]] |
| 허가권자 | 시장·군수·구청장. 허가·신고 수리, **감리자 지정**, 현장 점검 |
| 해체공사 감리자 | 해체계획서대로 진행되는지 확인·지도 |
| 해체공사 시공자 | 건설업 등록 업체 (구조물해체·비계공사업 등) |
| 석면해체·제거업자 | 고용노동부 등록 업체. 석면은 이 업체가 별도로 제거 |
| 폐기물 처리업자 | 건설폐기물 수집·운반·중간처리 |
