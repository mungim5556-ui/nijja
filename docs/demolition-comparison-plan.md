# 완전 철거 vs 분별 해체 경제성 비교 BIM — 데이터 요구사항과 구현 계획

## Context
ReClaim(현재 앱)은 IFC 가져오기, 콘크리트·강재 규칙 평가, 단가표, VRP 운송, 자재별 순경제성 계산을 이미 갖추고 있다. 하지만 **어떤 해체 공법을 쓸지**는 비교하지 않는다. 새 기능은 BIM(Revit→IFC) 물량을 바탕으로 **완전 철거 / 완전 분별 해체 / 최적 혼합안** 3가지 시나리오의 총비용·수익·공기를 계산하고, 단가 불확실성을 **몬테카를로 확률**("분별 해체가 더 경제적일 확률 X%")로 보여준다.

인터뷰에서 정한 조건:
- 사용자: **해체업체 견적·입찰** → 인건비·장비비·공기를 공종별로 나눈 내역이 필요하다
- 경제성 기준: 직접 비용·수익 + 공기 간접비 + 규제·인센티브 (탄소는 인증 항목 안에서만)
- 자재 범위: 구조재 + 주요 비구조재 (창호·유리·알루미늄, 문, 석고보드, 목재, 단열재, 설비)
- 물량 출처: Revit→IFC. 접합 방식 등은 **공유 매개변수 → IFC Pset**으로 넣는다
- 현장 조건: 현장 야적·분류 공간
- 단가 출처: **아직 정하지 않음** → 조사 단계(Phase 0)를 둔다
- 검증: **실제 해체 현장 데이터 있음** (견적서·반출 기록)

## 1. 필요한 데이터 목록 (핵심 결과물)

### A. BIM 모델 데이터 (Revit 공유 매개변수 → IFC `Pset_ReClaim`)
| 속성 | 값 예시 | 용도 |
|---|---|---|
| 부재 종류·재료명·부피/면적 | IfcWall, IfcWindow, IfcDoor, IfcCovering, IfcFlowSegment… | 물량(톤) = 부피 × 밀도 |
| `RC_Connection` 접합 방식 | 볼트 / 용접 / 모르타르·접착 / 일체타설 / 나사·클립 | 분별 해체 난이도·인시(사람×시간) |
| `RC_Separable` 분리 가능성 | 쉬움 / 보통 / 어려움 | 분별 회수율 |
| `RC_ReuseGrade` 재사용 등급 | 재사용 / 재활용 / 폐기 | 판매 경로 |
| `RC_Hazard` 유해물질 | 없음 / 석면 의심 / 확인 | 사전 제거 비용, 혼합 반출 금지 |
| `RC_Composite` 복합재 여부 | 예: 샌드위치 패널, 접착 단열재 | 분리 불가 → 혼합폐기물 |

### B. 자재별 단가 (자재 성상 × 처리 경로)
- 재료 밀도(t/㎥) 표: 콘크리트, 철근, 강재, 유리, 알루미늄, 석고, 목재, 단열재(EPS/글라스울), 동·PVC 배관
- 매각 단가(원/t): 재사용 부재, 고철, 알루미늄 스크랩, 동 스크랩, 폐목재
- 처리비(원/t): 성상별 분리배출 처리비 vs **혼합 건설폐기물** 처리비 (차이가 분별 해체의 핵심 이득)
- 출처 후보(Phase 0에서 확정): 건설공사 표준품셈 해체 항목, 조달청 가격정보(고철은 이미 연동됨), 한국건설자원협회 처리단가, 업체 실적 단가

### C. 공법별 작업량(생산성)·인건비·장비비
| 데이터 | 완전 철거 | 분별 해체 |
|---|---|---|
| 작업량 | 압쇄 ㎥/일 (장비 1대 기준) | 공종별 인시/㎡ 또는 인시/t (내장 철거, 창호 탈거, 설비 회수, 구조 해체) |
| 인원·장비 구성 | 굴삭기+압쇄기, 보통인부 | 숙련공·보통인부, 소형 장비, 크레인 |
| 단가 | 노임단가(원/인·일), 장비 임대료(원/일) | 같음 |
| 현장 분류 작업 | 거의 없음 (혼합 반출) | 분류 인력·컨테이너 수 |

### D. 공기·간접비
- 하루 작업 시간, 주당 작업일
- 일당 간접비(원/일): 현장관리비, 가설·안전관리비, 감리비
- 공기 = Σ(물량 ÷ 작업량) (선후행 관계는 층·공종 순서로 단순화)

### E. 규제·인센티브
- 분리배출 의무 위반 시 과태료·처리비 할증률 (완전 철거안에 적용)
- 순환골재 의무사용 공사에 공급 가능한 물량과 단가 가치
- G-SEED 자원순환 가점: 정성 표시 + 선택 금액 환산
- 해체허가/신고 구분(연면적·층수·높이 기준)과 감리 비용 → 두 안에 공통으로 넣되 분별안의 공기 연장분만 차이로 반영

### F. 현장 조건
- 야적·분류 가능 면적(㎡) → 동시에 보관할 수 있는 분류 컨테이너 수 → 부족하면 반출 횟수 증가 또는 외부 야적장 임대료(원/일)

### G. 불확실성 (몬테카를로 입력)
- 핵심 변수마다 분포(최소/최빈/최대, 삼각분포): 고철가, 혼합폐기물 처리비, 노임, 분별 작업량, 회수율, 공기
- 시행 횟수(기본 5,000회), 난수 seed(결과 재현용)

### H. 검증 데이터 (실제 현장)
- 실제 견적서(공종별 금액), 폐기물 반출 기록(올바로시스템 성상별 톤수), 실제 공기, 자재 매각 영수 금액
- 가능하면 해당 건물 도면 또는 Revit 모델

## 2. 구현 계획 (Phase 순서)

**Phase 0 — 단가·작업량 조사 (코드 없음)**
- 위 B·C·E의 기본값을 표준품셈·공공 단가에서 찾아 `assets/data/demolition_rates.json`으로 정리하고, 항목마다 출처·기준일을 단다.
- 실제 현장 데이터(H)를 받아 검증 세트로 정리한다.

**Phase 1 — BIM 입력 확장**
- `revit/`에 공유 매개변수 파일(`ReClaim_SharedParams.txt`)과 IFC 내보내기 Pset 매핑 안내를 추가하고, `revit/README.md`를 갱신한다.
- `assets/js/ifc.js`의 `MEMBER` 매핑에 IfcWindow, IfcDoor, IfcCovering, IfcRailing, IfcFlowSegment/IfcFlowFitting을 추가한다. `materialName()` 옆에 Pset 읽기를 더한다.
- 재료명 → 자재 분류(`MATERIAL_CLASSES`)를 지금의 2종(concrete/steel)에서 확장한다. 밀도표는 JSON에서 읽는다.

**Phase 2 — 시나리오 비교 엔진** (`assets/js/scenario.js` 새로 만듦, `engine.js` 재사용)
- `costScenario(state, mode)`의 mode는 `full` | `selective` | `optimal`. 결과는 공종별 {인건비, 장비비, 처리비, 운송비, 매각수익, 간접비, 과태료·인센티브, 공기} 내역이다.
- 운송비는 기존 `demandsByDestination` / `planRoutes`(CVRP)를 재사용한다. 완전 철거안은 거의 전부를 혼합폐기물 처리장으로 보낸다.
- 최적 혼합안: 자재(그룹)마다 `분별 순이익 − 완전 철거 순이익`을 비교해 이익인 것만 분별한다. 다만 늘어난 공기 간접비를 반영하도록 탐욕법으로 고르고, 다시 계산해 확인한다.
- 야적 면적 제약: 컨테이너 수 상한 → 반출 횟수와 외부 야적 비용을 다시 계산한다.

**Phase 3 — 몬테카를로**
- `simulate(state, n, seed)`: 분포에서 단가를 뽑아 3안을 반복 계산하고, 결과로 P(분별 < 완전), 비용 분포(P10/P50/P90), 변수별 영향도(상관계수 기반 토네이도)를 낸다.
- seed를 고정할 수 있는 PRNG를 쓴다 (`demo.js`의 LCG 방식 참고).

**Phase 4 — 화면·보고서** (`assets/js/app.js`)
- 새 단계 "공법 비교": 3안 비용 내역 누적 막대, 공기 비교, 확률 분포 히스토그램, 토네이도 차트를 넣는다 (dataviz 스킬 기준).
- 3D 뷰어(`viewer3d.js`): 최적 혼합안에서 분별/일괄 철거 부재를 색으로 구분한다.
- 단가 화면에 공종 단가·분포 입력을 추가한다. 보고서에 견적 내역서 형식의 표와 가정·출처·기준일을 넣는다.

**Phase 5 — 검증**
- 실제 현장 1건을 모델링해 넣고, 공종별 견적 금액·성상별 반출 톤수·공기를 실제 값과 비교한다 (목표 오차: 총액 ±20%, README KPI와 같은 기준).
- 오차가 큰 항목은 Phase 0 단가를 보정하고, 보정 내역을 기록한다.

## 4. 검증 방법
- `python -m http.server 5173`로 앱을 띄우고 "예시 프로젝트 불러오기" → 공법 비교 단계에서 3안이 계산되는지 확인한다.
- Pset이 들어간 IFC(apartment_plan.py 모델 + 공유 매개변수)를 가져와 비구조재와 접합 방식이 자재 목록에 나오는지 확인한다.
- 같은 seed로 몬테카를로를 두 번 돌리면 같은 결과가 나오는지 확인한다. 단가 하나를 극단값으로 바꿔(예: 혼합폐기물 처리비 ×3) 결과가 분별 쪽으로 기우는지 확인한다.
- Playwright로 공법 비교 화면 스크린샷을 찍어 차트와 3D 색상을 확인한다.
- 실제 현장 데이터와 비교한 오차표를 보고서로 남긴다.

## 5. 사용자에게 받아야 할 것 (다음 단계)
1. 실제 해체 현장 자료: 견적서, 반출 기록, 공기, 도면 또는 모델
2. 단가 조사 방향 확인: 표준품셈 접근 가능 여부, 협력 업체 단가 제공 가능 여부
3. 야적 면적 등 현장 조건 실측값
