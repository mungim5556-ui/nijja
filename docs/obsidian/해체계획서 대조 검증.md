# 해체계획서 대조 검증

관련: [[분별해체 경제성 BIM 구현 계획]]

Revit 모델 7개를 자동 분석하고, 같은 건물의 해체계획서·입찰 내역서 값과 비교한 기록.

## 1. 검증 흐름

1. Revit 모델 **복사본**을 `C:\ReClaim\inbox`에 넣는다 (원본은 건드리지 않음)
2. `run_reclaim.bat` → pyRevit이 Revit을 무인으로 열어 분석 → `out\<모델>.reclaim.json` + `_ReClaim.rvt` 사본 + 결과 서버(Cloudflare Worker) 전송
3. 해체계획서 값을 `C:\ReClaim\plans.json`에 옮긴다 (형식: `scripts/fixtures/plans.example.json`, 쪽·표 위치를 `_src`에 기록)
4. `python scripts\validate_plan.py C:\ReClaim\out C:\ReClaim\plans.json --out ...\계획서대조.md` → 항목별 오차, ±20% 밖은 ⚠

`.reclaim.json`의 `check` 항목에는 대조용 값이 있다. 성상별 t, 철근 t, 콘크리트 ㎥, 모델 밖 혼합 보정 t, 시나리오별 연인원·최대 인원·공기·굴착기 시간이 들어 있다.
- 계획서의 **고철**은 모델의 철근 + 철물과 비교한다.
- 계획서의 **혼합**은 원단위 잔여 + 마감재와 비교한다.

모델별 용도·연면적은 `reclaim_config.json`의 `"models"` 항목으로 따로 줄 수 있다.

- **연면적:** 범위가 같은 4건은 0~5% 오차라 Revit 물량 읽기는 믿을 만하다. 노량진·천마산은 모델이 전체 층을 세고 계획서는 해체 대상 면적만 적어서 2배 차이가 난다.
- **공기·인원:** 계획서 값은 계약 기간이고 비계·가설·살수·신호수·안전요원이 포함된다. 엔진은 순 해체 작업일만 센다. 소규모일수록 −70~−100%로 나온다.
  - → 할 일: "순 해체일 / 총 공기" 분리 (11/14 회의 공기 규칙 대기)

- **폐기물 톤:** 계획서 7건 중 6건이 '-' 또는 '추후 기입'이다. 명동 350t은 부분 범위 값이라 비교할 수 없다.

## 5. 천마산야영교육장 천마의집 — 나라장터 내역서 대조

### 자료

공고 **20241134566-00** 「천마산야영교육장 철거공사 건설폐기물 처리용역」. 발주는 서울특별시교육청학생교육원이고, 2024-12-04 개찰.

- **폐기물 내역서 (공종별내역서):** 혼합건설폐기물(건설폐재류에 가연성 5% 이하 혼합) **785.14 t**
  - 단가: 처리 68,359원/t + 상차·운반(16t 암롤, 30km) 74,570원/t = 142,929원/t
  - 785.14 × 142,929 = **112,219,274원**으로 추정가격과 원 단위까지 일치한다.
- **과업지시서:** 기간 21일. 정산은 계근장 기준이다. 동절기에는 임도가 통제돼 실제 착수는 3~4월이다.
- **첨부 해체계획서:** 126.18㎡, 지상 2층, 높이 6.85m, 석축 + 철근콘크리트조, 1975년 준공.
  - 해체순서 7번이 "기초 및 옹벽 해체"다.
  - p33 「석축 및 옹벽 존치 및 철거계획도」(A-102): 빨간 점선 철거 구간, 파란 점선 존치 구간.
- 785 t ÷ 126 ㎡ = **6.2 t/㎡**로, 비주거 RC 원단위(약 1.7 t/㎡)의 3.6배다. 대지 석축·옹벽·기초가 포함됐기 때문이다.

### 남은 차이 해석

- ③ 이후 남은 차이는 약 **197 t (−25.1%)**다. 건물 본체 물량에 대해 근거 있는 값(도면 표기)은 다 넣었다.
- 남은 차이는 모두 **땅속·대지 쪽**이다. 기초 치수는 전부 가정이고, 석축 높이는 ±0.3m 수준으로 추정했다.
- 나머지 후보:
  - 석축 뒤채움 반출
  - 외부 계단
  - 예정 물량의 여유분. 처리 항목이 "건설폐재류" 하나라 흙·잡석이 섞였을 수 있다.
- 785 t은 **예정 물량**이다. 실제 처리량은 계근장 정산값이다. → 정보공개청구로 정산 계근량을 받으면 최종 검증이 된다.
- **교훈:** 해체계획서의 철거 범위도(기초·석축·옹벽)를 모델에 같이 그려야 폐기물량이 맞는다. 건물만 모델링하면 저층·노후·경사지 건물에서 크게 과소 산정된다.
