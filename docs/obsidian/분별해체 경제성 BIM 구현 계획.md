# 분별해체 경제성 BIM 구현 계획

> [!summary] 한 줄 요약
> 2023년 논문의 비교 구조(**시공비 증가 − 처리비 감소 − 재활용 수익**)를 계산 엔진의 뼈대로 삼고, 자체 BIM 편집기에서 그린 **부재 단위 물량**을 넣어 완전 철거 / 분별 해체 / 최적 혼합안 3가지를 비교한다. 첫 검증 목표는 **논문 사례를 우리 엔진으로 똑같이 재현하는 것**이다.

> [!warning] 원문 확인 필요
> 논문 사이트(koreascience.kr)가 이 작업 환경에서 연결을 끊어 원문 PDF를 읽지 못했다. 아래 논문 내용은 **검색 결과 요약에서 확인한 것만** 적었다. 표의 수치, 단가, 공식은 원문을 보고 [[#7. 원문에서 뽑아야 할 것]] 목록을 채워야 한다.

### 1.1 확인된 내용 (검색 요약 기준)
- **사례 건물**: 5층 공동주택, 공사면적 2,400㎡
- **비교 항목** 3가지
  1. 분별해체를 하면 **늘어나는 시공비** (인력·시간 증가)
  2. 혼합폐기물이 줄어 **줄어드는 처리비**
  3. 분리 배출한 폐기물의 **재활용 수익**
- **결과**: 일반 해체보다 **총 34,727천원 절감**이 예상된다

### 1.2 같은 연구 흐름의 앞선 논문
결론이 서로 다르다. 이 차이를 설명하는 것 자체가 우리 프로그램의 가치다.

| 연도 | 논문 | 결론 |
|---|---|---|
| 2009 | [분별해체 현장조사에 의한 발생량·공정 분석](https://koreascience.or.kr/article/JAKO200923153957948.page) (이종찬·송태협) | 분별해체 시 혼합폐기물이 예측량보다 크게 줄어듦 |
| 2012 | [건축물 분별해체 제도 도입을 위한 기초연구](https://koreascience.kr/article/JAKO201223153958798.page) (박지선·송태협) | 분별해체 총비용이 **약 5.8% 더 높음**. 기술 향상과 처리 구조 개선으로 극복 가능 |
| 2013 | [적용 대상 건축물 범위 설정](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002161159) (박지선·송태협·최동호) | 모든 건물에 적용은 어려움 → 연면적·용도별 **단계적 도입** |
| 2014 | 공동주택 분별해체 시험시공 (김효진·강인석·김창학) | 폐기물 처리비 **약 17% 감소** |
| 2023 | **기준 논문** | 재활용 수익까지 넣으면 **34,727천원 절감** |

> [!tip] 핵심 통찰
> 2012년에는 손해, 2023년에는 이득이다. 갈린 이유는 **재활용 수익을 넣었는지**, **혼합폐기물 처리비가 얼마나 올랐는지**다. 그래서 프로그램은 결론 하나만 보여주면 안 되고, "처리비가 X원/t 넘으면 분별이 유리" 같은 **조건**을 보여줘야 한다. → [[#5. 몬테카를로·손익분기]]

## 2. 논문 모델 → 프로그램 공식

### 2.1 논문의 비교식 (구조)
$$
\Delta = \underbrace{\Delta C_{시공}}_{분별로\ 늘어난\ 시공비} - \underbrace{\Delta C_{처리}}_{줄어든\ 처리비} - \underbrace{R_{재활용}}_{재활용\ 수익}
$$
$\Delta < 0$ 이면 분별해체가 경제적이다.

### 2.2 우리 프로그램의 시나리오 총비용
시나리오 $s \in \{완전철거, 분별해체, 최적혼합\}$ 마다:

$$
TC_s = C^{시공}_s + C^{처리}_s + C^{운반}_s + C^{간접}_s + C^{규제}_s - R^{매각}_s
$$

| 항목 | 계산 | 논문에 있음? | 데이터 출처 |
|---|---|---|---|
| $C^{시공}$ 시공비 | Σ 공종별 물량 × 품(인/단위) × 노임 + 장비시간 × 장비비 | ✅ | 표준품셈, 시중노임, 기계경비 |
| $C^{처리}$ 처리비 | Σ 성상별 톤 × 처리단가 (완전철거는 대부분 **혼합** 단가) | ✅ | 중간처리단가, 나라장터 낙찰가 |
| $R^{매각}$ 재활용 수익 | Σ 성상별 톤 × 회수율 × 매각단가 | ✅ | 조달청 고철·비축물자 |
| $C^{운반}$ 운반비 | 기존 VRP 엔진 (`planRoutes`) | ⬜ 원문 확인 | 앱의 차량·목적지 설정 |
| $C^{간접}$ 공기 간접비 | 일당 간접비 × 공기(일) | ❌ **확장** | 표준품셈 간접비율 |
| $C^{규제}$ 규제 | 혼합 배출 과태료·할증, 순환골재 의무사용 가치 | ❌ **확장** | 건설폐기물법 |

### 2.3 논문보다 확장하는 부분
- **부재 단위 계산**: 논문은 건물 전체 물량, 우리는 BIM 부재마다 계산 → 어느 부재를 분별할지 고를 수 있다
- **최적 혼합안**: 부재(그룹)마다 $\Delta_i < 0$ 인 것만 분별. 공기 간접비가 늘어나는 것까지 반영해 탐욕법으로 고른다
- **야적 공간 제약**: 분류 컨테이너를 놓을 자리가 부족하면 반출 횟수와 외부 야적 비용이 늘어난다
- **불확실성**: 단가를 범위로 넣고 "분별이 더 경제적일 확률"을 계산한다

### 0단계 — 논문 사례 재현 (코드 전)
- [ ] 논문 PDF 확보 (KoreaScience에서 직접 내려받기)
- [ ] 사례 건물 물량표, 성상별 폐기물량, 단가표를 `assets/data/paper2023_case.json`으로 옮기기
- [ ] 엑셀로 논문 계산을 손으로 재현해 **34,727천원**이 나오는지 확인
- [ ] 논문이 쓴 단가 출처와 기준 연도를 기록 → 우리 기본 단가표의 초안

> [!note] 왜 먼저 하나
> 우리 엔진이 맞는지 판단할 **정답지**가 생긴다. 2단계 엔진에 이 JSON을 넣으면 논문과 같은 답이 나와야 한다(허용 오차 ±1%).

### 1단계 — 자체 BIM 편집기
Revit처럼 부재·자재별로 그리고, 부재마다 정보를 입력하는 웹 편집기.

- [ ] **층·그리드**: 층 높이, 축선(X1, X2… / Y1, Y2…) 설정
- [ ] **그리기 도구**: 벽, 기둥, 보, 슬래브, 창호, 문, 마감(천장·바닥), 설비 배관
- [ ] **속성 패널**: 부재를 클릭하면 아래 [[#4. BIM 부재 데이터 모델]] 항목 입력
- [ ] **물량 산출**: 형상에서 부피·면적 계산 → 밀도표로 톤 환산 (`ifc.js`의 `meshVolume` 재사용)
- [ ] **성상 자동 분류**: 재료 → 건설폐기물 성상(아래 [[#4.2 건설폐기물 성상]]) 매핑
- [ ] **기준층 복사**: 기존 "기준층 자재 복사" 기능을 편집기에도 적용
- [ ] **IFC 가져오기·내보내기**: Revit 모델은 보조 입력으로 계속 받기
- [ ] 3D 화면은 기존 `viewer3d.js`(three.js) 확장

### 2단계 — 시나리오 엔진 (`assets/js/scenario.js`)
- [ ] `costScenario(state, mode)`: mode = `full` | `selective` | `optimal`
- [ ] 공종 분류: 내장 철거, 창호 탈거, 설비 회수, 구조 해체, 현장 분류
- [ ] 완전철거: 내장재 대부분 → 혼합폐기물, 구조체 압쇄
- [ ] 분별해체: 공종 순서대로 해체, 성상별 분리 반출
- [ ] 운반비: `demandsByDestination` → `planRoutes` 재사용
- [ ] **테스트**: `paper2023_case.json` → 논문 결과 재현

### 3단계 — 몬테카를로·손익분기
- [ ] 변수마다 삼각분포(최소·최빈·최대): 혼합폐기물 처리비, 고철가, 노임, 분별 작업량, 회수율
- [ ] seed 고정 난수로 5,000회 반복 → P(분별 < 완전철거), P10/P50/P90
- [ ] 토네이도 차트: 어떤 변수가 결론을 가장 크게 흔드는지
- [ ] 손익분기: "혼합폐기물 처리비가 ___원/t 이상이면 분별이 유리"

### 4단계 — 화면·보고서
- [ ] 새 단계 "공법 비교": 3안 비용 누적 막대, 공기 비교, 확률 히스토그램
- [ ] 3D: 최적 혼합안에서 분별 부재 / 일괄 철거 부재를 색으로 구분
- [ ] 견적 내역서 형식 표 (공종 × 인건비·장비비·처리비·수익)
- [ ] 모든 단가에 출처·기준일 표시

### 5단계 — 실제 현장 검증
- [ ] 갖고 있는 실제 해체 현장 1건을 편집기로 모델링
- [ ] 견적서 공종별 금액, 올바로 반출 기록(성상별 톤), 실제 공기와 비교
- [ ] 목표 오차: 총액 ±20% (README KPI 기준)
- [ ] 오차 큰 단가를 보정하고 보정 내역 기록

## 4. BIM 부재 데이터 모델

### 4.1 부재(Element) 스키마
```js
{
  id: "W-3F-012",
  category: "wall",          // wall | column | beam | slab | window | door | finish | mep
  level: 3,                  // 층
  grid: "X2-X3/Y1",          // 위치
  geometry: { ... },         // 형상 → 부피·면적 자동 계산
  layers: [                  // 복합 부재는 층별 재료
    { material: "콘크리트", thickness: 0.18 },
    { material: "석고보드", thickness: 0.0125 }
  ],
  connection: "mortar",      // bolt | weld | mortar | monolithic | screw | adhesive
  separable: "medium",       // easy | medium | hard
  reuseGrade: "recycle",     // reuse | recycle | dispose
  hazard: "none",            // none | suspected | confirmed (석면 등)
  composite: false,          // 샌드위치 패널 등 분리 불가 복합재
  condition: "fair",         // 기존 앱의 외관 상태
  damage: ["crack"],         // 기존 앱의 손상 태그
  photoId: "p4"              // 기존 앱의 현장 사진 연결
}
```

> [!info] 복합 부재가 중요한 이유
> 벽 하나에도 콘크리트 + 단열재 + 석고보드가 붙어 있다. 완전철거는 이것을 통째로 **혼합폐기물**로 보내고, 분별해체는 **층마다 다른 성상**으로 나눈다. `layers`가 있어야 이 차이를 계산할 수 있다.

### 4.2 건설폐기물 성상
「건설폐기물의 재활용촉진에 관한 법률 시행령」 별표 1의 분류를 기준으로 한다 (⬜ 원문으로 최신 목록 확인).
