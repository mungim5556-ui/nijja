# 분별해체 경제성 BIM 구현 계획

> [!summary] 한 줄 요약
> 2023년 논문의 비교식 **(시공비 증가) − (처리비 감소) − (재활용 수익)** 을 계산 엔진의 뼈대로 삼는다. 여기에 자체 BIM 편집기에서 그린 **부재 단위 물량**을 넣어 완전 철거 / 분별 해체 / 최적 혼합안 3가지를 비교한다. 첫 검증 기준은 **논문 사례(−34,727천원)를 우리 엔진으로 똑같이 재현하는 것**이다.

> [!check] 논문 재현 완료 (손계산)
> 논문 표 3·4·5·8·9의 모든 수치를 다시 계산해 **34,727천원 절감**까지 정확히 일치함을 확인했다. → [[#3. 논문 재현과 검증]]

### 1.1 연구 목적
선행 연구들은 분별해체의 시공, 폐기물 발생량 같은 **단계별 부분 검토**만 했다. 이 논문은 **시공 → 폐기물 처리 → 재활용** 전 과정의 경제성을 처음으로 함께 묶어 분석했다.

### 1.2 제도 현황 (논문 2장)
**국내**
- 「건설폐기물 재활용촉진법」 제6조: 배출자는 성상별·종류별 **분리 배출** 의무
- 같은 법 제5조: 발주자는 분리배출·보관·처리·재활용 비용을 **공사금액에 계상**해야 함
- 시행령 제6조의2: **2021년부터 연면적 500㎡ 이상** 건축물 철거공사는 **분별해체 의무**
- 현실: 일부 공공 발주에서 분별해체 비용은 계상하지만, 실제로는 기존 방식대로 해체함
- 석면: 함유량 **1% 이상**이고 해체면적 **50㎡ 이상**이면 등록업자만 해체 가능 (산업안전보건법)

**일본** (건설리사이클법)
- 해체공사는 바닥면적 **80㎡ 이상**이면 분별해체 의무 (국내보다 엄격)
- 대상 폐기물: 폐석면, 폐목재, 폐콘크리트·폐벽돌, 폐금속, 폐유리, 폐플라스틱
- 폐목재 재활용률이 80%를 넘음
- 분별해체 순서: ① 가구·설비 → ② 유해물질(석면, PCB, 프레온, 할론) → ③ 재활용 대상·처리방법이 다른 품목 → ④ 내장재 → ⑤ 콘크리트

> [!tip] 프로그램에 쓸 점
> 일본의 ①~⑤ 순서를 분별해체 시나리오의 **기본 공정 순서**로 쓴다. 기존 `generatePlan()`의 "사전 준비" 단계를 이 5단계로 나누면 된다.

## 2. 논문의 분석 방법과 결과

### 2.1 폐기물별 재활용 효용성 평가 (3.1절)
- 대상: 법정 18종 중 건설폐재류, 건설오니, 폐금속류, 혼합건설폐기물, 기타를 뺀 나머지
- 방법: 전문가 30명에게 6개 항목을 6점 척도로 평가 (항목별 가중치 없음)
  1. 재활용성 2. 재활용 인프라 3. 해체 시공성 4. 경제적 이득 5. 환경 영향 6. 시장성
- **결과 순위**: 폐합성수지 > 폐목재 > 폐판넬 > 폐섬유 > 폐유리 > 폐보드 > 폐타일·도자기
- 결론: 도입 초기에는 **폐합성수지와 폐목재**를 중심으로 분별해체해야 함

**해체 시공성 점수 기준** (표 1 중 우리 BIM의 `separable` 속성과 바로 연결되는 항목)

| 점수 | 기준 |
|---|---|
| 6 | 일반 작업자가 원형을 보존하며 해체 가능 |
| 5 | 특수 공구로 원형 보존 가능 |
| 4 | 전문 인력·공구로 해체 가능 |
| 3 | 습식 또는 금속 고정이지만 현장 해체 쉬움 |
| 2 | 무겁거나 작업자 노출 위험, 이물질 많음 |
| 1 | 현장 해체 시 작업자에게 위험 |

> [!tip] 프로그램에 쓸 점
> - 부재 속성 `separable`(분리 가능성)을 3단계 대신 **이 6점 척도**로 받는다. 논문 기준을 그대로 쓰면 근거를 댈 수 있다.
> - 최적 혼합안을 고를 때 효용성 순위를 **우선순위 기본값**으로 쓴다.

### 2.2 사례 조건
- 5층 공동주택 1동, **공사면적 2,400㎡**
- 비교 대상은 **내장재 해체 공정만**이다. 구조체 해체는 두 방법이 같다고 보고 제외했다
- 석면 해체비도 두 방법에 공통이라 제외했다
- 분별해체는 모든 폐기물이 아니라 **효용성이 높은 자재부터** 분리한다고 가정했다

**공정 비교 (표 2)**

| 공정 | 일반 해체 | 분별 해체 |
|---|---|---|
| 내장재 | 생활폐기물 처리, 비유해 폐기물 사전 철거, 석면 사전 철거, 떼기 쉬운 목재·합성수지만 사전 철거, **고정 자재는 철거 안 함**, 유리 등은 현장에서 부숴 일괄 처리 | 생활폐기물 처리, 비유해 폐기물 사전 철거, 석면 사전 철거, **성상별로 분리 가능한 폐기물 분별 해체**(창호, 천장재, 바닥재, 칸막이), 유리는 부순 뒤 따로 모아 선별, 벽지처럼 콘크리트에 붙은 자재는 분리 안 함 |
| 구조체 | 내장재와 같은 절단·압쇄 | 같음 |
| 폐기물 | 건설폐재류, 소각 대상, 혼합 건설폐재류로 반출 | 폐콘크리트(벽돌·블록 포함), 폐아스콘, 폐합성수지·폐목재, 소각 대상, 혼합 건설폐재류 |

### 3.3 원문에서 발견한 오류·불일치
| 위치 | 내용 | 처리 |
|---|---|---|
| 3.2.2 본문 | 혼합폐기물 단가를 "67,677톤/원"으로 씀 | 표 7·9의 **67,377원/t**이 맞음 (계산도 67,377 사용) |
| 결론 2 | "38,823원 절감" | **38,823천원**이 맞음 |
| 표 8·9 머리글 | 둘 다 "Conventional demolition" | 표 9는 분별해체 |
| 표 5 머리글 | 노임 단위를 "천원/㎡"로 표기 | 실제로는 **천원/인** |
| 표 3 vs 표 4 | 천장 모르타르(0.12) 품이 분별에서 빠짐, 바닥 타일이 0.20 → 0.020 | 오타인지 의도인지 불명. 그대로 쓰면 분별 품이 **0.30인/㎡ 적게** 잡힘 |
| 표 8·9 | 폐목재 35,000원/t, 폐합성수지 49,000원/t의 출처가 표 7에 없음 | 출처 미기재 |
| 표 8·9 합계 | 폐금속(0.0655 t/㎡)을 뺌 | 두 방법에 공통이라 뺀 것으로 보임 |
| 표 5 | 지붕공·조적공 품은 계산에서 뺌 | 두 방법에 같아서 상쇄 |

> [!warning] 표 3·4 불일치의 영향
> 표 4에 천장 모르타르 0.12와 바닥 타일 0.20을 일반 해체와 같게 넣으면, 보통인부 품이 1.04 → **1.34인/㎡**가 된다. 그러면 시공비 증가가 67,522 → **약 184,000천원**이 되어 **결론이 뒤집힌다**. 우리 엔진에서는 이 두 항목을 따로 확인하고, 실제 현장 자료로 검증해야 한다.

### 3.4 결론이 얼마나 단단한가 (손익분기)
| 조건 | 값 | 의미 |
|---|---|---|
| 재활용 수익이 **0**이면 | Δ = **+28,699천원** | 분별해체가 더 비쌈 (2012년 연구의 "5.8% 더 비쌈"과 같은 방향) |
| 재활용 수익 손익분기 | 논문 가정의 **45%** | 수익이 28,699천원 아래로 떨어지면 분별이 불리 |
| 폐합성수지 단가 손익분기 | **약 299천원/t** (논문 850) | 합성수지를 이 값 이상에 팔아야 분별이 유리 |
| 혼합폐기물 단가 차이 손익분기 | **10.4천원/t** (논문 98.8) | 수익이 있다면 처리비 차이는 작아도 됨 |

> [!important] 핵심 통찰
> 이 논문의 결론은 **재활용 수익 63,426천원**에 달려 있다. 그런데 이 수익은
> 1. 폐목재를 **100% 합판 제품**으로, 폐합성수지를 **100% 그래뉼**로 만든다고 가정한
> 2. **제품 판매가**이고 가공비, 운반비, 품질 손실을 빼지 않았다
>
> 따라서 실제 해체업체가 받는 **폐자재 매각가**보다 크게 잡혔을 가능성이 높다. 우리 프로그램은 이 값을 **범위**로 넣고, "분별이 유리할 확률"과 손익분기를 함께 보여줘야 한다.

| 야적 공간 고려 없음 | 분류 컨테이너 수 제약 |

### 4.3 프로그램 총비용식
시나리오 $s \in \{완전철거, 분별해체, 최적혼합\}$ 마다:

$$
TC_s = \underbrace{C^{인력}_s + C^{장비}_s}_{시공비\ (논문\ ①)} + \underbrace{C^{처리}_s}_{논문\ ②} + C^{운반}_s + C^{간접}_s + C^{규제}_s - \underbrace{R_s}_{논문\ ③}
$$

| 항목 | 계산 | 논문 | 출처 |
|---|---|---|---|
| $C^{인력}$ | Σ 부재 면적 × 품(인/㎡) × 노임 | ✅ 표 3·4·5 | 표준품셈, 시중노임 |
| $C^{장비}$ | 장비 시간 × 기계경비 | ❌ | 기계경비 산출표 |
| $C^{처리}$ | Σ 성상별 톤 × 처리단가 | ✅ 표 7·8·9 | 한국건설자원협회 |
| $C^{운반}$ | 기존 VRP (`planRoutes`) | ❌ | 앱 차량·목적지 |
| $C^{간접}$ | 일당 간접비 × 공기 | ❌ | 표준품셈 간접비율 |
| $C^{규제}$ | 혼합 배출 할증·과태료, 순환골재 가치 | ❌ | 건설폐기물법 |
| $R$ | Σ 성상별 톤 × 회수율 × 매각가 | ✅ (제품가 방식) | 물가정보, 조달청 |

## 6. BIM 부재 데이터 모델

```js
{
  id: "W-3F-012",
  category: "partition",     // wall | partition | column | beam | slab | ceiling | floorFinish | window | door | roof
  level: 3,
  grid: "X2-X3/Y1",
  geometry: { ... },         // → 면적·부피 자동 계산
  layers: [                  // 복합 부재는 층별 재료
    { material: "합판", thickness: 0.009, waste: "wood" },
    { material: "각재", thickness: 0.03,  waste: "wood" },
    { material: "합판", thickness: 0.009, waste: "wood" }
  ],
  workItems: ["벽.목공사칸막이", "벽.텍스합판"],   // 표 3·4의 품 항목과 연결
  connection: "screw",       // bolt | weld | mortar | monolithic | screw | adhesive
  separable: 5,              // 논문 표 1 해체 시공성 6점 척도
  reuseGrade: "recycle",     // reuse | recycle | dispose
  hazard: "none",            // none | suspected | confirmed (석면 1%·50㎡ 기준 판정)
  composite: false,
  condition: "fair",         // 기존 앱 외관 상태
  photoId: null
}
```

> [!info] `workItems`가 중요한 이유
> 논문의 품은 **부위 × 작업**(예: 천장 텍스·합판 0.015 → 0.050)으로 되어 있다. 부재마다 해당 작업을 연결해 두면, 부재 면적 × 품으로 인원이 바로 나오고 **어느 부재를 분별할지 바꿀 때마다 시공비가 다시 계산**된다.
