왜 필요한가

여러 전문가가 손으로 나눠 하던 해체 계획을, 하나의 흐름으로 묶었습니다.

위 수치는 서비스 목표 지표입니다.

가치 판단이 어렵다

콘크리트와 강재의 상태·가치·해체 난이도를 수치로 판단할 기준이 없습니다.

운송 계획이 따로 논다

차량 종류·적재량·일정·비용을 함께 따진 운송 계획을 만들기 어렵습니다.

순서 검토에 누락이 생긴다

해체 순서와 공법을 수작업으로 검토하면 빠지는 부분과 비효율이 생깁니다.

사용 흐름

입력부터 보고서까지 6단계

건축 연도, 현장 사진, 자재 정보를 넣으면 평가·물류·해체 계획이 이어서 계산됩니다.

  1. 건물·자재 등록

    건물 기본정보, 현장 사진, 자재의 재질·규격·위치·상태 입력

  2. 자재 평가

    재사용 가능성·예상 가치·해체 난이도·처리비를 규칙 기반으로 산정

  3. 운송 물류

    차량·적재량·거리 조건으로 VRP 경로와 대안 비교

  4. 해체 계획

    해체 순서·공법·장비 조합을 만들고 직접 수정

  5. 3D 검토

    부재 단위 블록 모델에서 단계별로 재생하며 확인

  6. 승인·보고서

    검토 의견과 승인 이력을 남기고 보고서로 내보내기

주요 기능

계획에 필요한 판단을 한곳에서

건물·사진·자재 등록

프로젝트별로 건물 정보와 현장 사진, 자재 정보를 등록하고 누락을 미리 점검합니다.

  • 필수 항목·사진 형식 검사
  • 사진 해상도·밝기 품질 점검

재사용 자재 평가

재사용 가능성, 예상 가치, 해체 난이도, 처리비를 규칙 기반 점수로 계산하고 근거를 보여줍니다.

  • 자재별 판단 근거 표시
  • 신뢰도·추가 검토 표시

경제성·운송 물류

VRP 알고리즘으로 차량별 경로와 적재 계획을 만들고, 기본안과 대안의 비용을 비교합니다.

  • 우선 회수 순위
  • 계산 가정·가격 기준일 표시

해체 순서·공법·장비

자재 위치와 평가 결과로 단계별 해체 순서를 제안하고, 순서·공법·장비를 직접 고칠 수 있습니다.

  • 단계별 추천 근거
  • 저신뢰 단계 경고

3D 블록 시각화

부재 단위의 간소화된 3D 모델에서 해체 과정을 단계별로 재생하고 자재 정보를 확인합니다.

  • 재사용·폐기 색상 구분
  • 블록 선택 시 상세 정보

검토·승인·보고서

초안부터 승인까지 검토 흐름을 관리하고, 승인된 결과를 PDF·표 파일로 내보냅니다.

  • 의견·승인 이력 기록
  • PDF 인쇄·CSV 내보내기
